## Featured projects

### [ThinkPad Fan Control](https://github.com/da08ud/thinkpad-fan-control)

A Bash CLI for Linux ThinkPads that uses the native `thinkpad_acpi` fan interface. It reports fan and temperature status, requests level 7 as the recommended normal maximum, and can return control to firmware automatic mode. Its optional full-speed command is guarded by a warning and exact `ULTRA` confirmation. The project has been tested on a Lenovo ThinkPad T480s running Fedora 44; other ThinkPad models and Linux distributions are not yet verified. Full-speed is advertised by the tested driver's interface, but its behavior has not been validated across hardware.

### [WRO2025-NED — NEDrobotics](https://github.com/da08ud/WRO2025-NED)

A team project for **WRO Future Engineers 2025**. The repository documents an autonomous vehicle built around an Arduino Mega 2560, HC-SR04 ultrasonic sensors, a HuskyLens Pro camera, servo steering, motor control, and a 3D-printed chassis. The documented control approach includes ultrasonic wall following, PID steering, and traffic-sign color recognition. The repository includes Arduino code, Python serial utilities, CAD exports, and schematics. This was collaborative work by Team NEDrobotics; the repository does not assign individual ownership of each subsystem, so I present it as a team project rather than a solo build.
